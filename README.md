# PMLS Course Help & Discussion

This repository is a space for getting help with assignments, sharing solutions to common problems, and supporting each other as we learn computational biophysics together.

## How to Use This Space

**When you're stuck on an assignment:**

1. Click the "Issues" tab above.
2. Create a new Issue with a descriptive title like "Week 1: Error loading HIV data" or "Week 3: Plot not displaying".
3. In your Issue, include:
   - Which assignment you're working on
   - What you've tried
   - Error messages (copy/paste the full error if you can)
   - A brief description of what's not working
4. @ mention `@dr-kinder` if you need instructor help specifically.

**Helping classmates:**

- Browse open Issues to see if you can help someone.
- Comment on their Issue with suggestions or solutions.
- Share what worked for you when you encountered similar problems.
- This is encouraged! Helping others is one of the best ways to solidify your own understanding.

## Guidelines

- Be kind and constructive in all interactions.
- Include enough detail for others to understand your problem.
- Close your Issue once it's resolved (or mark it as solved in a comment).
- If you need **private** help with grades or personal matters, email or Slack me instead.
